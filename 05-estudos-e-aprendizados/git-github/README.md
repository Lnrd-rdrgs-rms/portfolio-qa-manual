# Git e GitHub

## Comandos praticados

```bash
git status
git add .
git commit -m "Descreve a alteração"
git push
git pull origin main
```

- `git status`: verifica o estado da cópia local.
- `git add`: prepara alterações para o próximo commit.
- `git commit`: registra as alterações localmente.
- `git push`: envia commits para o repositório remoto.
- `git pull`: busca e integra alterações do repositório remoto.
